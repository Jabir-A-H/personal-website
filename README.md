# Jabir Abdullah Haian - Personal Portfolio

One Shell, Multiple Faces. The more you look, the less you see.

## Tech Stack
- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion

## Development
```bash
npm install
npm run dev
```

## Deployment
This project is configured for static export (`output: 'export'`) and automatically deploys to Cloudflare Pages via GitHub integration on every push to the `main` branch.
